## English

- Fixed stale text overlapping new messages when logs are prepended. The read-only log control now paints an opaque, matching background and performs a complete repaint after batched insertion, trimming, and scrolling. Newest messages remain at the top; on-disk logs remain chronological.
- Section 3 lists L4N and DXVK versions newest first and selects the top entry by default. Identical versions are ordered by resource modification time; legacy resources with unknown versions remain available. Numeric component comparison correctly places 2.10 ahead of 2.9.
- Section 4 prefers EVO after update checks and falls back to Skeeto when only Skeeto is ready. Platform exclusivity and the base-deployment prerequisite are unchanged.
- Review added sorting support for manually imported archives without product prefixes, such as `v2.11.0.zip`. DXVK version numbers in legacy combined-package names are not misinterpreted as L4N versions.
- Long-log refresh, both native log-color callbacks, EVO default / fallback, version-ordering, and full race regressions passed, along with isolated cleanup tests using 25 real packages. Production deployment preserves personal resources and installation backups and includes rollback support.
- File deployment and UI tests do not constitute in-game acceptance testing. Real-account Steam operations and in-game behavior still require manual confirmation.
