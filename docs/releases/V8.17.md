# V8.17

## EVO 资源包驱动部署

- 修复 EVO 1.2.6 及后续版本拆分插件被旧版文件名单过滤的问题。
- 递归读取所选包的插件目录及子目录，随包数据、脚本、模型和声音按实际路径部署并记录 SHA256。
- 清理和回滚逐项匹配本次资源包清单，不删除其他插件或基础 L4N/DXVK 文件。
- 保留已有用户配置；新配置继承资源包默认值，再应用导航设置，避免重复目标。
- 检测已托管包的拆分插件缺失或内容变化，不再只依据两个旧核心文件判断完整性。
- 运行文件以资源包实际内容为准，不限制未来版本的目录和辅助文件名；仅排除包内元数据及备用 winmm/DXVK 加载链。
- 随包 EVO 更新为本地已校验的 1.2.7 资源包（内部 manifest 标注 1.2.7.2）。

已有旧版不完整部署：退出游戏后先“清理平台”，再选择 EVO“部署平台”。本次生产部署已按此流程重建清单。

验证覆盖：旧版包、新版拆分插件、未知命名、子目录资源、配置保留、覆盖备份、缺失模块检测、失败回滚、其他插件保护及竞态回归。游戏内功能仍需进图验证；磁盘校验不等于全部运行功能验证。
