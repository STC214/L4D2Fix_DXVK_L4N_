# V8.14

## 中文

- 界面重排为五个编号区域：检测网络、检测更新、L4N＋DXVK、Skeeto／EVO、日志。标题在左上边框缺口内居中，并使用独立亮白文字，避免系统主题影响可读性。
- 新增独立资源网络检测，检查 Steam／GitHub 接口及实际资源下载链路，记录逐项结果与耗时；仅做小流量抽样，不下载完整安装包或修改订阅。拒绝将 HTML／JSON 错误页判为下载链路通过。
- 支持直接检查更新；网络检测失败时提示不建议更新，更新失败时提示先检查网络。基础资源就绪后解锁基础部署，完整基础部署和对应平台资源就绪后解锁增强部署。空闲时两套清理均不受网络／更新前置条件限制，原有归属、游戏退出和互斥检查保持不变。
- 界面日志最新消息置顶，磁盘日志仍按时间顺序保存。修复过期版本刷新回调覆盖新状态的问题。
- 两轮完整竞争检测、隐藏原生界面／标题对比度／文字裁切测试及 25 个真实资源包隔离清理测试通过。生产目录部署保留个人资源和现有安装备份，并提供回滚。
- 网络抽样通过不保证后续完整下载速度或稳定性；真实 Steam 账号订阅／退订和游戏内运行效果仍需人工验收。

## English

- Reorganized the UI into five numbered sections: Network Check, Update Check, L4N + DXVK, Skeeto / EVO, and Logs. Bright white, independently rendered headings are centered inside the original upper-left border gaps for consistent readability across system themes.
- Added a standalone resource-network check covering Steam / GitHub APIs and actual resource download links, with per-item results and timings. It samples a small amount of data without downloading full packages or changing subscriptions. HTML / JSON error pages are not treated as successful download responses.
- Update checks can be started directly. Failed network checks advise against updating; failed updates recommend checking connectivity first. Base deployment requires verified base resources; enhancement deployment also requires a complete base installation and its corresponding platform resources. Both cleanup actions remain independent of network / update prerequisites when idle; existing ownership, game-exit, and task-exclusion checks remain in place.
- The UI shows newest log messages first while on-disk logs remain chronological. Fixed stale version-refresh callbacks overwriting newer state.
- Two full race-test rounds, hidden native UI / heading contrast / text-clipping checks, and isolated cleanup tests using 25 real packages passed. Production deployment preserves personal resources and existing installation backups and includes rollback support.
- A successful network sample does not guarantee later full-download speed or stability. Real-account Steam subscription / unsubscription and in-game behavior still require manual acceptance testing.
