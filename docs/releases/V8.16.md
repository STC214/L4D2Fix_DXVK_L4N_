## English

- Complete local resources deploy offline without an online check. The portable bundle retains 2 L4N versions, 4 DXVK versions (including two AMD-compatible variants), one Skeeto/EVO each, and both required Skeeto MODs.
- L4N checks Steam Workshop first, then the dedicated backup repository Releases, merging and deduplicating semantic versions. With fewer than 5 valid local versions, download the newest 5 missing versions; otherwise download every version newer than the local maximum only.
- Workshop VPK payloads are renamed to ZIP before inspecting their internal version. Backup ZIP/7z archives are supported natively. Downloads become selectable only after size, hash, structure and internal-version validation.
- Keep live DXVK updates and add a built-in 10-version catalog after network checks pass. Complete caches survive restarts; new Skeeto/EVO choices require all mandatory payloads to be ready.
- Network diagnostics now cover the L4N backup repository and attachment route. Updated documentation and bundled versions; base and enhancement deployment/cleanup remain independent.
