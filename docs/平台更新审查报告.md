# 平台更新与互斥部署审查

日期：2026-10-26（Asia/Shanghai）。本次没有修改实际游戏目录，没有运行第三方包内 DLL、BAT 或 PS1。

## 已实现

- 官方 API 一次查询 L4N、Skeeto、L4D2Evolved，校验身份与完整性，下载完成转为 ZIP；成功项立即刷新到界面，失败项不发布。
- 缓存 SHA256 校验、损坏重下、部分成功保留；通过 API 最新指针选择版本，不将文件名排序误当作最新版，预留历史版本选择参数。
- L4N＋DXVK 基础部署与增强平台独立清单；前置部署校验、增强平台互斥、未知代理/未托管平台保护。
- Skeeto 写入 `skeeto_nav 1`；Evolved 显式开启小地图和世界导航，处理已有 config2 覆盖。
- 平台部署失败自动回滚；清理依据已部署文件清单，无需选版本。变更文件先留档，保留用户新增 autoexec 命令与未托管文件。
- 基础文件、CSessionDefaults 与 Steam 配置不被增强平台接管；便携目录及游戏目录均有跨实例排他操作锁。
- 原界面说明迁入 [使用教程](使用教程.md)，不包含实时部署状态、日志框内容；右侧空间用于新控件与仓库教程链接，发布包同步附带新教程。

## 迭代修复

1. 官方 L4N 仅有 config_template 时补齐规范化 config 映射。
2. Evolved 排除备用 winmm 和渲染 DLL，仅允许明确的两个插件模块，保护其他插件。
3. 更新缓存校验与最新指针分离，支持历史资源存在及服务端回退版本。
4. Windows 文件替换遇短时占用时有限重试；清单改为随机临时文件、同步写入后替换。
5. 恢复入口对仅 Steam 配置备份保持兼容；失败时保留可重试清单。
6. 清理前留档平台自动更新及配置修改；清理 autoexec 仅移除本工具有标记的导航块。
7. 检查取消、损坏包、路径越界、未知代理、外来清理目标及多实例锁均有回归覆盖。

## 验收边界

本轮通过的是静态校验、下载、临时游戏目录部署/互斥/清理/故障回滚、原生控件与构建测试。尚未在真实游戏进程内验证小地图显示、导航路径或平台稳定性；不将文件配置成功表述成游戏运行验证。

平台自行生成且未列入工具安装清单的文件保持原样；手动安装的既有平台不被自动接管。不同增强平台间切换必须先清理，改变基础平台前也先清理增强平台。
