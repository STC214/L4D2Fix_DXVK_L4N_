## 复现与修复

| 编号 | 问题 | 修复与回归 |
|---|---|---|
| A01 | 新增文件清单的 relative 与 target 不一致时，可能绕过平台文件归属检查 | 所有清单项均校验规范化 relative 与实际游戏相对路径一致；覆盖不应删除的 CSessionDefaults 目标。 |
| A02 | 损坏的 Skeeto 导航标记直到还原循环末尾才报错，可能已经移除部分模块 | 开始清理前逐项只读预检；标记必须完整、唯一且独占一行；预检失败保留所有平台模块及清单。 |
| A03 | Evo 键名等号前的空格或制表符未剔除，可能保留重复的导航配置 | 比较前清理键名两侧空白，合并两个导航键，保留其他内容。 |
| A04 | 中断更新遗留的隐藏临时 ZIP 可能被列为可选版本 | 版本发现排除点开头的临时文件/目录，未验证资源不出现在下拉框。 |
| A05 | 配置留档目录原子重命名遇 Windows 短时占用可能偶发失败 | 复用有次数/时间上限的 sharing/access 重试，不先删除既有留档。 |
| A06 | 路径检查未覆盖 root 自身，资源目录本身是 junction/symlink 时可能写入链接外部 | 共享路径守卫拒绝链接/非目录 root；准备资源前检查缓存路径，保证拒绝前不写外部目录。 |

A01–A04 已先运行针对性测试复现失败，再修复为通过。另补充内嵌标记、资源 root 链接、Windows junction root 和文件 root 的回归用例。两轮收尾验证继续覆盖原有更新、部署、回滚和字体工具流程；结论限定于已审查及测试范围，不作“绝对无缺陷”的保证。
