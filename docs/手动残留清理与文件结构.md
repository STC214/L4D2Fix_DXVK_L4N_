# 手动残留清理与文件结构

## 分析范围

逐文件读取并计算 SHA256：**25 个本地资源包、556 条原始文件记录**，归并为 **311 条去重后的清理路径／内容特征**。包含 7 个 L4N 包（含 DXVK 合包及工坊快照）、16 个 DXVK 包、Skeeto 2.2.3 与 Evolved 1.2.5 工坊快照。这里是现有文件证据，不将快照版本声称为实时最新版。

所有文件名、包名、大小和 SHA256 见 [完整机器清单](平台文件结构清理清单.json)。内置特征为 `cmd/l4nfix/cleanup_signatures.json`；检查更新或准备资源成功后，新包原始结构登记到 `resources/cleanup-signatures.json`。清理同时读取四种资源目录的全部历史版本，不仅使用当前选择的版本。

## 界面行为

1. **有有效安装清单**：仍按原备份还原。清单损坏时停止，不伪装成“无清单”继续删除。
2. **没有安装清单**：进入手动残留模式，退出游戏后分析、输出日志清单并要求确认。左侧“一键清理”只处理 L4N＋DXVK；右侧“清理已部署平台”处理 Skeeto／Evolved，不要求选版本、补齐文件或先联网。
3. 全部候选文件先复制到 `resources/manual_cleanup_backups/<时间-随机标识>/files/`，核对 SHA256，保存 `manifest.json`、`rollback.ps1`，然后才删除或改写游戏文件。复制／校验失败不开始删除；文件被占用、变化或路径出现链接时停止并保留留档。
4. 仅删除空父目录，拒绝路径越界、符号链接和目录联接。不确认的共享文件、异常资源包及保留的混合导航命令不宣称已清干净。
5. 成功清理 Skeeto 内容后，沿用两项工坊退订逻辑；退订未确认时提示手动完成。工坊缓存由 Steam 管理，不清空 `addons/workshop`。
6. 完成后**弹窗并写日志**：**Steam 库 → 求生之路 2 → 属性 → 已安装文件 → 验证游戏文件的完整性**。校验用于恢复原版文件，不会自动删除所有第三方新增文件；未确认残留仍需查看日志。校验前勿进游戏。

无清单时不猜测 Steam 历史启动参数；手工填写过平台专用启动项时，请自行核对。既有安装备份和其他个人备份不删除。发布包排除 `manual_cleanup_backups`。

## 新版本与回滚

- 不固定版本号、文件数量，不要求核心文件齐全。
- 新完整包校验后从原始结构登记候选，含本工具正常部署时未采用的备用加载器。明确的专有目录兼容其新增文件；共享位置要求对应新包内容证据。
- 全新加载结构、没有下载过的新共享文件或改写后的通用代理仍保留／报告，不依赖模糊名称猜测。
- 留档内执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "完整路径\rollback.ps1"` 可恢复原内容。先检查全部备份和路径，拒绝覆盖清理后再次修改的文件；`-Force` 仅供人工核对后使用。Steam 校验后回滚会装回清理前内容，请明确选择。

## 验证范围

自动化覆盖：无清单、单个残留、两套边界、未知代理及原生 Necola 保留、半截 autoexec、锁文件、变化检测、链接阻断、新版本新增文件、逐文件留档、实际执行 PowerShell 回滚，以及 25 个真实本地包的不完整安装模拟。均使用临时游戏目录，不对生产游戏执行清理。
