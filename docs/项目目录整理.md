# 项目目录与发行包保留规则

## 当前目录

| 路径 | 用途 |
| --- | --- |
| `cmd/l4nfix/` | 主程序源码、测试、Windows 编译资源 `rsrc.syso` |
| `cmd/fontchange/`、`cmd/l4nfontchange/` | 两个字体工具 |
| `cmd/makeicon/` | 图标生成工具 |
| `internal/` | 内部共享代码 |
| `scripts/` | 构建、测试、打包、发行包清理 |
| `assets/windows/` | 主程序图标、管理员 manifest 源文件 |
| `assets/images/` | 图标参考图片 |
| `L4N_Go_Win32_Portable/` | 现用成品及 `resources/`，路径保持不变 |
| `dist/` | 最新三个版本的便携 ZIP |
| `docs/`、`archive/` | 使用文档与历史资源 |
| `.gotmp/`、`.gocache/` | 本地审查记录、撤回快照及缓存，不进入发布包 |

根目录保留 `go.mod`、`README.md`、Git 配置及两个兼容脚本入口。不移动现用资源、安装备份和配置留档。

## 命令

```powershell
# 普通终端回归；测试入口显式列出主程序 Go 文件，避开管理员 syso。
.\scripts\test.ps1 -Race

# 构建主程序及两个字体工具，旧入口继续可用。
.\build.ps1

# 打包并自动只保留最新三版。
.\package.ps1

# 预览或单独执行旧便携包清理。
.\scripts\prune-packages.ps1 -WhatIf
.\scripts\prune-packages.ps1
```

直接构建主程序的包路径为 `./cmd/l4nfix`；直接 `go test ./...` 包含管理员 syso，仍需要提升权限。普通终端推荐使用上面的测试脚本。

## 保留规则

只处理 `dist/` 直属的 `L4N_Go_Win32_Portable_YYYYMMDDHHmm.zip` 和旧无时间戳的同名包；按文件名构建时间排序，无时间戳包视作旧版。其他名字的 ZIP 不参与清理。仅在新包内容验证并成功发布后自动清理旧包，默认保留三个版本。

旧发行 ZIP 按要求删除，不另存一份占用磁盘；删除前的文件名、大小和 SHA256 记录在 `.gotmp/project_cleanup/`。该目录的撤回脚本只撤回源码目录整理和脚本/文档修改，不恢复已删除的旧发行包。

历史审查报告中的根目录 Go 文件路径是当时的快照路径。那些快照保留用于追溯；请勿用旧的回归命令或撤回脚本覆盖当前已整理的结构。
